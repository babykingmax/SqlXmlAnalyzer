## 使用方式

- 顶部两行显示文件、当前批次与语句、实际/估算数据状态、问题及未完成检查计数。配置变化时出现“重新分析”。
- 左侧“问题”仅包含真实诊断，支持搜索和严重度筛选；“检查状态”单独保留 Skipped/Failed，失败优先展示。“索引”保留原有建议、审核及导出流程。
- 点击问题或证据按完整 `PlanLocation` 联动语句与算子；点击节点保留问题列表。右侧显示事实、原因、建议、相关问题和证据，完整属性另设页签。
- 中间在“计划图”和“热点算子”之间切换。热点默认按估算自身成本排序，切换语句保持当前排序；列菜单调整可见列。
- 底部 SQL、XML、证据、参数统计、改写提案默认收起。“查看原始 SQL / XML”直接打开证据页。完整来源与配置信息可滚动查看。
- “适应图”缩放并居中当前可见页；“100%”只恢复原始比例；“定位选中”展开、翻页并定位已选算子。查找支持 NodeId、算子和对象名称，Enter 遍历匹配。
- 每页最多 64 个节点。页脚显示页范围、总数、折叠数量，跨页关系下拉可继续追踪输入和输出；下拉列表使用虚拟化。

## 指标与空间规则

- 自动模式在存在可比运行行数时显示“实际 / 估算”，否则显示估算成本。实际总行数与每次执行行数分别标注；缺失执行次数时不计算偏差，真实零值保留为零。
- 偏差为每次执行实际行数 / 估算行数。估算为零时显示“估算为 0”或“均为 0”，不制造无穷倍数。
- 估算成本明确分母；索引影响区分 SQL Server 估算影响和工具评分，不表达为实测收益。
- 1440 DIP 及以上默认同时显示两侧栏（280 / 320）；1100–1439 DIP 详情替换问题侧栏；更窄窗口切换图、问题、详情。侧栏宽度、辅助区、主视图、图显示方式和列配置保存至本机布局偏好文件，不保存 SQL 或对象名。
- 短窗压缩顶部和辅助栏，并将主视图切换入口移入第二行。正文基准为 13 DIP。默认连线无持续动画，远景隐藏一般数值标签。

```powershell
dotnet build SqlXmlAnalyzer.sln -c Debug -m:1
dotnet test SqlXmlAnalyzer.Tests/SqlXmlAnalyzer.Tests.csproj -c Debug -m:1
dotnet build SqlXmlAnalyzer.sln -c Release -m:1
dotnet test SqlXmlAnalyzer.Tests/SqlXmlAnalyzer.Tests.csproj -c Release -m:1

```

`WpfProbe.cs.txt` 使用真实 MainWindow、ViewModel 和生产 XAML，在离屏窗口中用软件渲染采集截图，不连接数据库。每次运行将证据写入独立的 `runs/<时间>-<配置>/`，包括布局矩阵、截图、检查结果及绑定错误记录。样例 SQL 为人工生成的数据。

矩阵覆盖浅/深色、1280×720 / 1366×768 / 1920×1080、100% / 125% / 150% / 200% 的等效 DIP 尺寸及位图缩放。高度断言测量整个计划图控件（含图工具栏和分页导航）相对工作区的比例。大图验证 100 / 1000 / 5000 节点、64 节点渲染上限、跨页定位、查找和语句切换。

这里的图控件高度不是 Nodify 编辑器的净画布高度；主图控件占比通过，不能证明可读绘图区充足。后续 PW-01 需分别记录净画布宽高、节点显示尺寸、当前比例及用户任务结果。

这些证据不等同于物理显示器 DPI、真实键盘操作或屏幕阅读器验收。自动化覆盖了 WPF 路由按键/按钮事件及选择状态；实际显示设备、辅助技术与 DBA / SQL 开发者任务仍需人工检查，详见 [验收矩阵](acceptance-matrix.md)。
