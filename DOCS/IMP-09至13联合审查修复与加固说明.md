# IMP-09 至 IMP-13 联合审查修复与加固

2026-09-09：修复联合 review 中确认的三项 P2 问题：诊断入口的能力标记不一致、平行死锁边端点离开节点边界、清空结果后输入快照仍被 ViewModel 引用。新增 38 项回归测试，Debug / Release 全量测试各 1579 项通过。

## 修复行为

| 问题与触发输入 | 修复后的行为 | 主要实现 |
| --- | --- | --- |
| 合法空 `Statements` 在读取/CLI 中有 `PlanStatements`，默认诊断入口却没有；`InternalInfo` 中的同名算子/计数被误算为能力 | 读取、默认计划/节点诊断从共享服务推导能力。空语句容器保留 `PlanStatements`；不透明扩展及错误位置的运行计数不再产生虚假能力 | `PlanCapabilityService`、`InputRecognitionService`、`PlanAnalysisContext` |

### 能力口径与缓存

标准 ShowPlan 的 `PlanStatements` 来自根下 `BatchSequence/Batch/Statements`，允许空容器。`PlanOperators` 来自已识别语句所拥有的 `QueryPlan` 中的 `RelOp`；`RuntimeCounters` 必须来自算子的直接 `RunTimeInformation/RunTimeCountersPerThread` 路径。遍历跳过 `InternalInfo` 和外部命名空间子树。计数元素存在仍不表示数值完整或有效，指标状态继续由 IMP-11 的事实服务判断。

`PlanCapabilityService` 按 XML 根使用 `ConditionalWeakTable` 缓存，同一未修改文档只扫描一次；XML `Changed` 事件令缓存失效，下次按当前树重新推导。首次扫描为 O(N)，遍历及缓存命中入口均检查取消。缓存不作为文档的额外强根。明确传入的能力快照（包括 `None`）保持调用方约束；旧报告仍为当时快照，XML 变更后需要重新读取/分析才能获得新报告。

### 几何与生命周期加固

方向归一化先缩放最大分量，避免平方计算溢出。NaN、无穷坐标/偏移，以及不可表示的节点间距离作为 `DEADLOCK_GEOMETRY_INVALID` 预期错误抛出。中心重合时使用确定的水平方向，保证有限结果。偏移限制在两个节点最小半尺寸减 1 像素内；资源/进程组合上限为 24，现有 ±16 布局保持间距。

清空操作可重复执行；生产代码只释放引用，不强制执行 GC。内存回归测试保持 ViewModel 存活，并独立验证两个输入、两个 1 MiB 字节缓冲及 XML 文档均不可达。

## 异常、DUMP 与日志

几何计算边界接入既有 `ExceptionPolicy` / `UnexpectedErrorReporter`。非法数值记录错误，不生成 DUMP；未知组件异常生成经过 `MinidumpValidator` 验证的 Windows DUMP 和异常侧车，然后重新抛出原异常。DUMP 写入失败保留失败说明及侧车，不替换原异常；同一个异常继续使用已有去重报告。共享能力推导沿用读取/分析入口的既有异常边界。

| 构建 | 输出级别 |
| --- | --- |
| Debug | DEBUG、WARN、ERROR、CRITICAL |
| Release | ERROR、CRITICAL |

新增调试日志只包含能力枚举及操作说明；偏移被限制时记录警告，不追加 SQL、对象名称或原始输入。回归通过实际日志文件验证四种级别及 Release 过滤。

## 检索依据

优先读取 Microsoft 官方资料；三处问题均涉及 .NET XML 查询、对象生命周期与绘图几何，因此没有引入 SQL Server 领域规则、阈值或新的第三方依赖。

- [Microsoft：XContainer.Descendants](https://learn.microsoft.com/en-us/dotnet/api/system.xml.linq.xcontainer.descendants?view=net-8.0) 说明查询返回后代元素；由此结合本项目 IMP-10/11 的归属契约，不能将任意深度的同名元素直接视为算子证据。这一归属筛选是项目实现结论。
- [Microsoft：Rect](https://learn.microsoft.com/en-us/dotnet/api/system.windows.rect?view=windowsdesktop-8.0) 提供矩形位置和尺寸定义；本轮按最终偏移直线求矩形边界交点。
- [Microsoft .NET GC 官方文档源码](https://github.com/dotnet/docs/blob/main/docs/standard/garbage-collection/fundamentals.md) 说明 GC 从应用根追踪可达对象；释放 ViewModel 对输入结果的强引用，才允许无其他引用的快照被回收。
- [Microsoft MSAGL 的 Curve.cs](https://github.com/microsoft/automatic-graph-layout/blob/master/GraphLayout/MSAGL/Core/Geometry/Curves/Curve.cs) 中 `TrimEdgeSplineWithNodeBoundaries` / `FindNewStart` / `FindNewEnd` 对最终曲线与节点边界求交后裁剪。该成熟实现用于核查处理顺序，本项目使用自己的矩形射线公式。
