## 行为与兼容性

规则注册 ID、分支 ID、默认严重度和配置 ID 保持不变。`RuleScope` 在原有枚举值之后追加 `QueryPlan`。以下六条规则现在按每个 QueryPlan 执行，因此多语句、游标和嵌套计划的诊断数量及定位可能变化：

- RULE_003_PARAM_SNIFFING
- RULE_014_SERIAL_PLAN_REASON
- RULE_017_LARGE_MEMORY_GRANT
- RULE_019_CACHE_RECOMPILE
- RULE_028_STATS_USAGE
- RULE_029_MEMORY_GRANT_DOC

上述六条及 RULE_013_ANTI_PATTERN、RULE_024_SCALAR_SUBQUERY_PATTERN、RULE_032_MEMORY_SPILL 的规则版本更新为 2.0.0，以区分修复后的诊断行为。既有配置仍按原 RuleId 生效。CLI 选项及输出要求见 [CLI 审核重放与输入保护](CLI审核重放与输入保护.md)。

粘贴的 TSV 不包含原 SQL 数据类型及排序规则元数据。直方图根据文本推断键类型，使用 EQ_ROWS 或 AVG_RANGE_ROWS 作说明，不复现完整 SQL Server 基数估算。没有排序规则时，非精确字符串区间返回未知。SSMS 的大写 `NULL` 标记与同文本的字符串值无法仅凭 TSV 区分，按未知处理；缺失参数和空字符串通过原始参数信息区分。
