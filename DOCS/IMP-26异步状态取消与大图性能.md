## 操作状态与取消

| 状态 | 含义 |
| --- | --- |
| Idle | 尚未开始，或结果已清除 |
| Loading | 读取输入快照 |
| Parsing | XML/XEL 解析、识别与预算检查 |
| Analyzing | 身份建模、规则诊断和改写审核准备 |
| PreparingView | 图、树及布局准备和分批提交，尚未完成 |
| Ready | 当前请求的分析和首屏图提交完成 |
| Cancelled | 已确认取消，不再接收该请求的结果 |
| Partial | 存在可用结果，但输入不完整、诊断失败或改写/展示阶段失败 |
| Failed | 本次操作失败，可重新打开输入 |

状态栏显示中文状态、详情提示和“取消分析”。状态由 AnalysisSessionCoordinator 管理，携带 RequestId、单调 Revision 和阶段耗时。取消令牌与 IsCurrent 同时防止旧任务提交；视图再以渲染版本及选择对象身份检查。A 被 B 替换后，即使 A 的读取器忽略取消并迟到返回，也不能覆盖 B。PreparingView 的通知回调中取消，同样会在提交前被拦截。分批提交中取消会移除未完成的计划图。

取消通过 .NET 8 CancelAsync 立即标记令牌，回调在线程池执行；回调异常被观察并进入异常策略。取消确认时间不代表底层工作已完全停止：XML、规则和改写循环协作检查令牌，第三方单次解析等不可抢占工作在返回后检查。阶段计时是墙钟时间；PreparingView 包含后台准备、调度等待和控件呈现。

打开 XEL 时先设置事件列表，再在同一请求中等待首个事件分析和图提交，不再由选择事件另启一个重复请求。未处理记录导致的 Partial 保留在状态栏详情，不用模态提示阻塞打开流程。手动切换事件创建新请求并保留原始记录身份与输入完整性状态。

## 后台准备和大图呈现

输入快照、XML/XEL 识别、规则、图模型、树模型和布局准备在线程池执行。图形资源冻结后供后台模型读取；图标按路径、长度及修改时间缓存，最多 128 项。UI 提交默认每批一个节点/连线，批次之间以 Dispatcher Background 优先级让出执行权，并在每次添加前后检查取消与请求版本。

先测量未优化版本，再采用以下措施：

- 执行计划图每页最多 64 个算子，只绘制两个端点都在当前页内的连线；分页不代表计划被截断。完整算子、诊断、身份和原始 XML 保留。
- 上一页/下一页遍历完整范围；诊断、指标表和键盘 Home/End/方向键定位可自动打开目标所在页。折叠后按可见算子分页，大图重新布局在后台完成。
- “当前计划指标表”绑定全部算子并启用行列虚拟化；操作符树按展开创建节点，另一算子树移除外层 ScrollViewer 并启用虚拟化。
- 初始图直接消费已有诊断和缺失索引结果。SQL 改写审核复用同一个输入、身份模型和诊断快照，不再创建临时 SQL 文件或再次调用分析引擎。快照与源 XML 不一致时拒绝复用。

分页仅限制图控件容器数量，不构成整个进程的内存上限。原始 XML、身份模型、规则结果和完整算子视图模型仍在内存中；超大 SQL 文本和诊断集合也可能造成 UI 停顿。现有读取预算继续生效，未承诺任意规模输入都能流畅显示。

## 异常、DUMP 与日志

输入损坏、读取错误、预算超限和取消走既有已知错误策略；未知读取、分析、视图准备、图分页及取消回调异常进入 ExceptionPolicy / UnexpectedErrorReporter，记录错误与致命信息，调用 WindowsMiniDumpWriter 生成 DUMP。同一异常去重；DUMP 写入失败也显示明确失败信息，不声称已生成文件。

Debug 输出调试、警告、错误、致命四类日志；Release 仅输出错误、致命，运行时打开 verbose 也不能绕过 Release 门禁。新增日志主要记录请求号、阶段与数量，不新增 SQL 正文输出。沿用本地诊断文件目录和隐私提示，不上传 DUMP。

## 验证与限制

新增 32 项单元测试，覆盖九态转换、迟到结果、取消回调、分页边界、快照复用、Dispatcher 分批中取消/替换、实际 Windows MiniDump、转储失败和日志门禁；同时调整既有测试，验证改写路径确实不再读取临时 SQL 或重复分析。未生成覆盖率报告。

实际 WPF 宿主验证取消后不报成功、批次中取消后清除图、失败后重开、忽略取消的 A 迟到、1000 算子跨页证据/键盘定位，以及真实 XEL 两个死锁事件切换。详细计数、截图和 Debug/Release 全量结果以验证摘要为准。

100/1000/5000 算子和真实多事件 XEL 的测量保留硬件、输入 SHA-256、冷/热运行、阶段、输入队列延迟和进程峰值工作集。候选 P95 <100 ms 和取消确认 <500 ms 不是产品 SLA；未达项在验证说明单独列出。该宿主使用离屏窗口和软件渲染，不能代替物理显示器 DPI、实体键盘、屏幕阅读器或真实生产负载验收。
